# TerritoryWar —— 弹珠领土战争

Godot 4.7 + C# 的俯视视角弹珠领土战（纯 CPU 模拟）。

## 这是什么

四家各守一角，用弹珠抢地盘。一局的循环：

```
领土面积 → 每秒产能 → 炮塔把能量投成「抽签球」 → 掉进左侧钉板
   → 穿过 ×2/×4/×8 或转盘门攒倍率 → 落进底排某格 → 才决定这一轮做什么
   → 弹珠出去抢地盘（踩敌境要花命：小球烧寿命、大球烧能量）
   → 打掉对方基地就灭掉一家，最后存活者获胜
```

画面由三块**世界空间**内容铺满整个画面（没有任何 HUD）：**左上是掉落球钉板、
左下是领土占领面板、右侧是 1000×1000 的战场**。摄像机是固定的，启动时一次框满，
之后不动。

三块内容各自在做什么：

| | 说明 |
| --- | --- |
| **掉落球钉板**（左上） | 每队的炮塔按节奏往板里投一颗球，球在钉阵里落下、被左右摆动的横板抽一下，穿过 ×2/×4/×8 或转盘门攒倍率，最后落进底排 7 格之一：发射 / 弹药 / 护盾 / 大球 / 弹幕 / 扇形 / 烟花。**球只是抽签，本身不直接涂地** |
| **领土占领**（左下） | 四家各一行：名次、色块、占比条。数据每 0.2 秒刷一次 |
| **战场**（右侧） | 弹珠滚出去涂色。**小球**是散开的子弹（能量固定、有寿命）；**大球**是炮塔花本钱打出来的"保龄球"（出膛随机摇能量、直线横推、撞墙或撞球才改向，能一路磨穿敌境）。大球上会显示它的剩余能量 |

两条撑起全部平衡的规则：

- **踩敌境要付代价** —— 小球烧寿命、大球烧能量，花完就没了；自己家里走多少路都不花钱。
  于是"扩张"和"存活"天然互相牵制，不需要额外的惩罚机制。
- **每格占领成本随时间从 1 涨到 16** —— 压制无限扩张；同时地图开局就按"离哪个基地最近"
  分完，没有中立地，四家一上来就接壤。

## 怎么用

### 运行

需要 **Godot 4.7-stable mono**（.NET 8）。

编辑器里打开项目按 `F5`；或者命令行：

```powershell
dotnet build -v q --nologo
<你的 Godot 控制台版> --path .
```

（控制台版形如 `Godot_v4.7-stable_mono_win64_console.exe`；用带 `_console` 的那个才能看到日志。）
启动时会打印一行 `[自检] 通过 N 项 …`，看到 `✗` 说明某项约定没满足。

### 操作

| 按键 | 作用 |
| --- | --- |
| `Space` | 暂停 / 继续 |
| `R` | 重开一局 |
| `1` / `2` / `3` | 速度 1× / 2× / 4× |
| `Esc` | 退出 |

屏幕上没有 HUD，所以按键提示只有这里；**一局结束（或平局）时会往控制台打一行 `[对局] …`**。

### 调参

所有旋钮都在检查器里，不用改代码：

- `GameRoot` 节点：按分组排列（地图与势力 / 经济 / 炮塔 / 掉落球板 / 大球 / 战场 / 能量数字）。
  例如 `DropFeedInterval`（投料频率，人口的闸门）、`BigShotInterval`（大球出膛节奏）、
  `BigBallEnergyMin·Max`（大球出膛能量的随机区间 = 它的大小与寿命）。
- **面板的版面与物理**：钉板和两块面板的尺寸、位置、配色、字号都在各自的场景节点上 ——
  在编辑器里拖节点、拉 `Polygon2D` 的 `scale` 就等于改版面；钉板还会**从这些节点读钉的半径、
  门的矩形**，所以拖钉子就是改物理。
